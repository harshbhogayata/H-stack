1. fs.cpSync keeps timestamps? And path.join with absolute paths

    Accepted answer · 1,204 votes · 2021-08-19

    Yes. fs.cp/fs.cpSync behave like cp -a: mode and timestamps are preserved, so incremental tools keep working. Also note that path.join treats an absolute segment like cd does: path.join('dist', '/assets') returns '/assets', so strip the leading slash first.
