# Sprout

Sprout is a React app. It has stories and a garden. This README describes the code.

## Running it

Open `src/screens/GardenScreen.jsx` in the playground of your choice; there is no build step in this repo snapshot.

## Where things live

- `src/theme/tokens.css` — colours, type and shapes
- `src/components/` — shared pieces (RoundButton, StoryCard, ParentGate)
- `src/copy/en.json` — every word a child sees
- `src/data/progress.js` — reading progress, kept on the device
